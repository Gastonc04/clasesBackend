# Práctica de Vectores y Matrices - Java 21

Proyecto Maven para practicar arreglos unidimensionales (vectores), bidimensionales (matrices), generación de números aleatorios e ingreso de datos con `Scanner`.

## Requisitos

- Java 21
- Maven 3.9+

## Ejecutar los tests

```bash
mvn test
```

Al comenzar, los métodos contienen implementaciones pendientes y los tests fallarán. La idea es resolver cada ejercicio hasta que todos los tests pasen.

## Ingreso de datos (Scanner)

Implementá el ejercicio 13 en `com.ivo.practica.Main`. Cuando esté listo, ejecutá esa clase desde el IDE.

## Ejercicios

### Vectores
1. Sumar todos los elementos.
2. Obtener el valor máximo.
3. Contar números pares.
4. Invertir un vector.
5. Buscar un elemento.

### Matrices
6. Sumar todos los elementos.
7. Obtener la suma de una fila.
8. Calcular la diagonal principal.
9. Transponer una matriz.
10. Encontrar el valor máximo.

### Generación de números
11. Generar un vector aleatorio de `n` enteros en un rango inclusivo.
12. Generar una matriz aleatoria de enteros en un rango inclusivo.

### Scanner
13. En `Main`, leer por teclado el tamaño y los elementos de un vector, mostrarlo y (si ya resolviste 1 y 2) imprimir suma y máximo.
